SQL Customer & Order Analysis
Analyzed customer orders using MySQL to solve real business problems. Created a complete relational database with 3 tables - Customers, Orders, and Employees. All tables are connected with Primary Key and Foreign Key to maintain data integrity and avoid duplicate data.

What I Did:
Solved 12 business problems using INNER JOIN, LEFT JOIN, Subquery, DATEDIFF, LIMIT, OFFSET, CASE WHEN, and Aggregate Functions like SUM, AVG, and COUNT. Started with basic SELECT queries, then moved to filtering, sorting, grouping, and finally complex JOINs and Subqueries.


Key Work:
Found Top 5 Highest Orders to identify high-value customers and their buying patterns.
Identified Pending Orders above 10000 to help finance team focus on payment follow-ups and improve cash flow.
Created Revenue Report with 18% GST, showing Order Amount, GST Amount, and Total Amount with GST for each order.
Built Employee-Manager Hierarchy using Self JOIN to show clear reporting structure.
Created Customer Loyalty Category using CASE WHEN - Gold, Silver, Bronze based on total spending.
Analyzed orders in last 30 days using DATEDIFF, and found customers who never placed an order using LEFT JOIN.
Did city-wise analysis using GROUP BY to find which city gives maximum revenue.

What I Learned:
How to design tables, how to convert business questions into SQL queries, when to use JOIN vs Subquery, and how to make reports for decision-making. This project improved my logical thinking, data reporting, and problem-solving skills.

Tools Used:
MySQL, SQL, MySQL Workbench
